# 《定分止爭錄》畫面風格指南

> **用途**：過場動畫（Google Flow：Veo 3.1／Omni 1.1）、場景底圖、立繪卡與遊戲介面的共同視覺規則。
> **依據**：ADR-0006。角色的外貌與服裝另見 `characters.zh-TW.md`；過場內容以 `docs/story/master-script.zh-TW.md` 為準。
> **狀態**：第一版。第 2 節的風格鎖定段與第 6 節的色票，在試產（第 9 節）後可能調整。

## 1. 一句話定調

**一部拍得很安靜的明代歷史正劇，配上一本乾淨的帳冊。**

影像寫實、內斂，不炫技；介面像攤開在桌上的紙本文件，資訊清楚，裝飾極少。參考《盛世天下：女王的權力遊戲》的「寫實影像＋2D 介面」結構，但不沿用它的華麗紅金雕花。

| | 要 | 不要 |
|---|---|---|
| 光 | 窗光、天光、燭光、炭火 | 柔焦美顏、霓虹、逆光光暈 |
| 色 | 低飽和；每幕一個主色 | 高飽和紅金、整片橙青調色 |
| 人 | 有皺紋、有毛孔、衣服有摺痕與磨損 | 偶像劇妝髮、過白的皮膚 |
| 鏡頭 | 電影感的慢速運鏡：軌道、升降、推近、移焦（見 5.1） | 快速運鏡、手持晃動、無人機環繞、變焦急推 |
| 介面 | 紙、墨、一點朱紅 | 滿版雕花邊框、粒子特效 |

## 2. 風格鎖定段

所有影片與靜態圖的生成提示，都以這一段開頭，**原封不動貼上**，後面才接角色的固定描述與該鏡頭的內容。

```text
Photorealistic live-action historical drama, China, Ming dynasty, 1570s–1580s. Shot on a full-frame cinema camera with a 50mm lens, shallow depth of field, natural motivated lighting, restrained low-saturation color grade, fine film grain. Historically accurate Ming dynasty Han Chinese clothing, hairstyles, architecture and furniture. Real skin texture, visible fabric weave and wear. Cinematic camera work on a stabilized rig: slow deliberate dolly, crane and push-in moves, composed framing with foreground depth, motivated rack focus. 24fps, 16:9. No text, captions, subtitles, logos or watermarks anywhere in the frame.
```

**禁用清單**，視工具支援放進負面提示，否則附在提示末尾：

```text
Avoid: Qing dynasty queue hairstyle or shaved forehead, Manchu clothing, Korean hanbok or gat hats, Japanese kimono, fantasy armor, modern objects, eyeglasses, glossy beauty-filter skin, heavy makeup on men, anime or illustration style, on-screen text, extra fingers, duplicated people.
```

明代官帽與朝鮮服飾外形相近，模型容易混淆，所以禁用清單特別點名。

## 4. 考據守則

寫提示與審片時的檢查項。服飾細節以角色設定集為準。

- **髮式**：成年男子一律束髮於頂，戴網巾或帽；不可出現清代辮髮。
- **官服**：烏紗帽、圓領袍、胸前方形補子。顏色依品級——一至四品緋紅，五至七品青（深藍），八九品綠。
- **宦官**：無鬚；帽子無兩側帽翅。
- **建築**：木構、斗拱、青磚灰瓦；宮殿為朱牆黃瓦。府衙公堂有公案與屏風。畫面中的匾額與文書一律不可辨讀，避免模型生成亂碼字。
- **器物**：算盤為上二下五珠；戥子是稱銀子的小桿秤，約一尺長，配小銅盤。
- **不要畫面內文字**：公文、匾額、書冊需要讓玩家讀到的內容，一律由遊戲介面疊上。

## 5. 過場的片段規則

### 5.1 鏡頭語言

全劇過場只用下面這一套運鏡，這是風格統一的主要來源。分鏡腳本裡每一段都從表中選**一種**運鏡，並沿用表中的英文寫法。

| 代號 | 運鏡 | 用在 | 提示寫法 |
| :--- | :--- | :--- | :--- |
| 升降 | 攝影機緩緩下降或上升 | 開場交代地點、收尾拉遠 | `slow crane down` / `slow crane up` |
| 推軌 | 沿直線緩緩向前推進 | 進入場景、逼近人物 | `slow dolly in` |
| 橫移 | 平行於人物緩緩橫向移動 | 依序帶過多個人物 | `slow lateral dolly, left to right` |
| 推近 | 由中景緩推到近景 | 一句關鍵台詞、一個決定 | `slow push-in from medium to close-up` |
| 移焦 | 機位不動，焦點由前景物轉到人物，或相反 | 物件與人的關係（戥子與程衡） | `locked-off shot, rack focus from … to …` |
| 定鏡 | 機位完全不動 | 沉默、對峙、反應 | `locked-off static shot` |
| 微距推近 | 貼近小物件緩慢推進 | 戥子、算盤、筆尖、佛珠 | `macro shot, very slow push-in` |

共同規則：

- **鏡頭組**：遠景 35mm，中景 50mm，近景 85mm，物件用微距。提示裡寫明焦段。
- **速度**：所有移動都是「慢」。一段之內鏡頭走的距離不超過畫面寬度的三分之一。
- **前景**：遠景與中景盡量有前景遮擋（柱子、炭盆的熱氣、人的肩膀），增加縱深。
- **高度**：對皇帝用略低的機位，對跪著的程衡用貼近地面的機位，對百姓用平視。
- **一段一種運鏡**，不在同一段裡先推再搖。
- **轉場**由遊戲端處理（硬切或墨色暈開），影片本身不做淡入淡出。

### 5.2 片段單位

- **一段 4–10 秒，一段只做一件事**：一個動作、一個情緒轉折，或一句開口台詞。反應鏡頭可以短到 4 秒。
- 30 秒的過場拆成三段以上，每段各自成立，再用下列方式銜接：
  - **同一個連續動作**：用「延伸」接下去。
  - **換景或換角度**：直接硬切，或用墨色暈開轉場（由遊戲端做）。
- 每段影片結尾留約半秒不剪，方便疊字幕。

### 5.3 提示的固定結構與生成流程

每一段的提示分成兩塊：

```text
起始畫面提示（給圖片模型）
[風格鎖定段]
[場景句]
[站位句；只在多人畫面使用]
[角色描述，含每個人的朝向與視線落點]
Composition: [景別、焦段、機位、前景].
[禁用清單]

動態提示（給影片模型，搭配起始畫面）
[鏡頭運動].
[表演句]
Action: [誰看哪裡；誰做了一個什麼小動作].
Sound: [環境音]. [有無人開口；開口者與台詞].
```

- **每個過場先做一張主場景圖**（該過場的全景），定下場景、站位與衣著。其他段落的起始畫面都從這張圖改出來，不另外從文字生成。
- **一段只給起始畫面**，不給結束畫面；起訖差異大的段落寧可拆成兩段硬切。
- **有起始畫面時，動態提示不重複描述畫面裡已有的東西。**
- 不經起始畫面、直接以文字生成影片時，把兩塊接在一起。

### 5.3a 表演與構圖規則

這幾條是為了避免人物像站樁的假人：

- **不寫「沒有人動」。** 靜止的戲寫成「有呼吸、會眨眼、重心與手有小動作」（各分鏡的表演句），並為每一段指定**一個**主要的小動作：吞嚥、撥一顆佛珠、視線移動、呼出一口白霧。
- **每個人都要有視線落點**，寫明看誰或看哪裡。沒有寫的人，模型會讓他看鏡頭。
- **每個人都要有身體朝向**，並說明與場中地位最高者的關係。臣子不背對皇帝，也不直視皇帝。
- **不拍正面對稱的多人畫面。** 多人全景從某個角色的斜後方拍，其他人是側面或四分之三側面。
- **一個畫面最多兩張看得清楚的臉。** 認臉靠單人近景；全景只要求位置與衣色正確。
- **機位守在同一側。** 每個過場在站位圖上定一條軸線（通常是對話兩人的連線），所有機位都在軸線的同一邊，兩人的視線方向才會相對。
- **畫外音不靠影片模型生成**，另外製作後由遊戲端疊上。
- **場景裡不該有人的地方，明寫沒有人**；會出現文字的東西（匾額、招牌）用構圖裁掉。

### 5.4 台詞政策

- **預設不開口**。過場由老年程衡旁白帶過，畫面是人物的動作與神情。旁白另外配音，不在影片內生成。
- **字幕由遊戲疊上**，不燒進影片；這樣中英文切換不必重生成影片。
- **開口台詞**只有下表這些。每句獨佔一段，景別用近景或中近景，說話者正面或四分之三側面對鏡。
- **語音來自 Flow Character**：開口的角色在建立時就選定範例語音並填寫自訂風格（見角色設定集的語音設定表）。同一個角色全劇只用一組語音設定，中途不更換。

## 6. 遊戲介面

### 6.1 原則

1. **介面是紙，影像是窗。** 場景底圖與立繪卡是寫實影像；所有文字、數字、按鈕都在紙色面板上。
2. **一個畫面只問玩家一件事。** 搜證時不出現分配控制項；分配時不出現算學指標。
3. **紅色只有一個意思：有人不平。** 朱紅保留給妒線、不平的表情框與警示，其他地方不用。
4. **數字要大、要對齊。** 估值與所得是遊戲的核心資訊，用等寬數字。

### 6.2 色票

| 名稱 | 色碼 | 用途 |
| :--- | :--- | :--- |
| 宣紙 | `#F3EBDC` | 面板底色 |
| 舊紙 | `#E4D7BF` | 次要面板、表格隔行 |
| 墨 | `#1F1B18` | 主要文字、線條 |
| 淡墨 | `#6B625A` | 次要文字、說明 |
| 朱 | `#B5372B` | 妒線、不平、警示、印章 |
| 官青 | `#2F4A63` | 主要按鈕、程衡與玩家相關的標記 |
| 秧綠 | `#5E7B5A` | 滿意、通過 |
| 舊金 | `#A8894F` | 「巧」字印、極少量的強調線 |
| 夜 | `#12100E` | 影片與底圖上的遮罩（搭配透明度） |

三家在第三幕各有一個識別色，只用在案台標頭與立繪卡的細框：外朝用緋（`#8E2F2A`）、薊鎮用鐵灰（`#4A4F55`）、內廷用絳紫（`#6A3B52`）。識別色不可單獨承載資訊，旁邊一定有文字。

### 6.3 字體

| 用途 | 字體 | 備註 |
| :--- | :--- | :--- |
| 標題、人名、印章 | 楷體類（建議霞鶩文楷 TC） | 帶手寫感，對應參考圖的題字 |
| 對白、說明 | 宋體類（建議思源宋體 TC） | 長文閱讀 |
| 數字、算式 | 無襯線等寬數字（建議思源黑體，開啟 tabular-nums） | 估值表、所得、乘積 |

實作時先確認專案現有的字體載入方式，再決定是否新增字體檔。

### 6.4 元件

| 元件 | 樣式 | 與參考圖的差異 |
| :--- | :--- | :--- |
| **立繪卡** | 直式圓角矩形，寫實半身像，下方一條紙色名牌（官職小字、姓名大字）。細墨線框。 | 保留卡片版式；拿掉金色雕花框 |
| **對話** | 被點到的立繪卡放大到畫面一側，另一側是紙色對話框，台詞中的估值數字以官青粗體標出。 | 沿用參考圖二的左右分割，但對話框固定位置、不用漫畫式氣泡尾巴 |
| **定分手冊** | 右側可收合的紙頁，一張估值表：列是物品、欄是人。尚未問到的格子留白。 | — |
| **分配案台** | 每位當事人一個案台（立繪卡在上、托盤在下）。可分割之物是十格的橫桿，一格一成；不可分割之物是一張可拖曳的物品牌。 | — |
| **即時反應** | 立繪表情切換，加一句貼在卡片旁的短台詞。 | — |
| **斷案卷宗** | 由上往下展開的長卷，一次揭示一項指標，周先生的說明在卷側。 | — |
| **妒線** | 立繪卡之間的朱紅箭線，粗細代表差額。 | — |
| **去一物** | 點一下被眼紅那一方托盤裡的物品牌，牌子暫時翻面變灰，妒線即時重算。 | — |
| **考語印章** | 圓角方印蓋在卷末：不稱職（淡墨）、平常（墨）、稱職（朱）；「巧」字印為舊金。 | — |
| **字幕與旁白** | 畫面底部置中，白字加細墨邊；旁白用楷體，對白用宋體並在前面標人名。 | 與參考圖相同位置 |
| **目標提示** | 畫面上方一條窄橫幅，顯示周先生當前的提示。 | 對應參考圖「目標達成」橫幅，但常駐、可收合 |

### 6.5 版面（16:9）

- **搜證**：場景底圖滿版，底部一排立繪卡，右側定分手冊。
- **分配**：底圖壓暗；上半部是並排的案台，下半部是尚未分配的物品。
- **揭曉**：案台縮到上方三分之一，卷宗在中央展開。
- 最小支援寬度以橫拿的手機為準；低於此寬度時定分手冊改為抽屜。

## 8. 審片檢查表

每一段影片或靜態圖通過以下檢查才收下：

- [ ] 臉與 Flow Character 的臉部圖是同一個人；側面與背面也沒有走樣。
- [ ] 服裝顏色、補子、帽子與角色設定集一致。
- [ ] 沒有辮髮、清式服裝、朝鮮式帽子、現代物件。
- [ ] 畫面內沒有任何文字或亂碼字。
- [ ] 手指數正確，沒有多出來的人。
- [ ] 沒有人看鏡頭；每個人的視線都落在場景裡的某個人或某樣東西上。
- [ ] 人物有呼吸與細微動作，不像定格；多人畫面不是正面排成一列。
- [ ] 站位與朝向和分鏡的站位圖一致。
- [ ] 一段只做了一件事，結尾有可剪接的空檔。
- [ ] 色調落在該幕的主色範圍內。
- [ ] 開口台詞的嘴型與台詞長度大致相符；不開口的段落沒有人在說話。

## 9. 試產

在全面生成之前，先驗證風格鎖定段與角色一致性：

1. 依角色設定集，在 Flow 建立**程衡（青年）**與**萬曆帝**兩個 Character：生成臉、製作身體、選取語音並貼上自訂風格。
2. **轉身測試**：每個角色各生成一段慢慢轉身一圈的片段。Flow 已沒有多角度視圖，這是確認側面與背面（帽翅、鬍鬚、補子、袍色）的唯一方法。
3. **語音測試**：讓兩人各說一句清單上的台詞，確認音色、語速與國語咬字。
4. 依 `docs/art/storyboards/cs-00.zh-TW.md` 第 9 節的順序生成：先做主場景圖，再做 G 段（戥子）與 F 段（程衡近景說「臣只會分東西」）。
5. 把臉部圖、全身圖與各段影片的截圖放進 `docs/art/refs/`，並記下選定的語音名稱。
6. 對照第 8 節檢查表，調整風格鎖定段、固定描述、製作身體提示與語音風格，再推廣到其餘角色。
